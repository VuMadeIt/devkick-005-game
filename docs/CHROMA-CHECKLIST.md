# Chroma submission checklist (deadline Jan 7, 2027, 11:45pm PT)

Submit at https://submit.chromaawards.com/

- [ ] Public, embeddable web link (not private, unlisted or password-protected)
- [ ] Download link to a gameplay video
- [ ] Thumbnail image
- [ ] Category: Arcade & Party (one category per project)
- [ ] English in-game text, captions on voice lines
- [ ] Tool tags + proof: Meshy, ElevenLabs (screenshots of generations, `assets/manifest.json`, % estimate)
- [ ] Original or licensed content only
- [ ] Submitter 18+
- [ ] Optional: post on social tagging @chromaawards and each tool (Submission of the Day)
- [ ] Optional: Behind-the-Scenes: Game Division video (1-10 min, separate entry)
