# Devin brief template

Copy this into a new Devin session. One session per task. Short and exact beats long and vague.

```
Repo: sadmanc/devkick-005-game. Read AGENTS.md and docs/IDEA.md first.

Task: <one working step, e.g. "two players on one keyboard can move and bump each other off the arena">

Files: <the files to create or change>

Done when:
- npm run check passes
- <the exact thing a person sees when they play it>
- no console errors in the browser, works at 844x390

Don't: <what to leave alone, e.g. "don't touch public/assets or index.html">

Open a PR titled "<short title>" with what changed and how you checked it.
```
